# Student Profile Card Application

## Project Overview

This project is a ReactJS-based Student Profile Card application that allows users to enter student information through a form and dynamically generate student cards.

The project demonstrates:

* Component-based architecture using React
* Dynamic state management using useState
* Reusable components
* Form handling
* Responsive UI design

---

## Features

* Add student details using a form
* Display student information in reusable cards
* Dynamic rendering using React state
* Horizontal card layout
* Interactive hover effects
* Responsive design

---

## Technologies Used

* ReactJS
* JavaScript (ES6+)
* CSS3
* Vite
* HTML5

## Installation Steps

### Clone Repository

git clone <repository-url>

### Navigate to Project Folder

cd student-profile-app

### Install Dependencies

npm install

### Run Development Server

npm run dev

### Open Browser

http://localhost:5173

---

## Usage

1. Enter student details in the form.
2. Click **Add Student**.
3. Student cards will appear dynamically below the form.
4. Multiple cards can be added.
